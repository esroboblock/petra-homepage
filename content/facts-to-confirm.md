# 게시 전 확인 목록

체크되지 않은 항목은 확정 사실이나 수치로 홈페이지에 게시하지 않는다.

## 회사·문의

- [ ] 대표자명을 공개 회사소개와 법적 고지 중 어디에 표시할지
- [ ] 공개할 주소 범위와 정확한 법적 고지 주소
- [ ] 대표 전화번호
- [ ] 공개 문의 이메일과 수신 담당
- [ ] 개인정보처리방침에 사용할 책임자·연락처
- [ ] 법적 푸터에 필요한 회사정보의 최종 범위

## 부품 수급

- [ ] 현재 취급 가능한 제조사·부품군
- [ ] 국내·해외 조달 범위
- [ ] 정품, 추적성, 보증과 반품 정책
- [ ] 최소 주문수량, 견적 기준과 결제조건
- [ ] 사급·도급 자재의 지원 범위와 책임
- [ ] 단종·대체품 검토를 실제 서비스로 제공하는지

## SMT·생산 연계

- [ ] 부품공급 사업의 계약 주체와 Petra의 역할
- [ ] SMT 제작의 계약 주체와 협력 법인
- [ ] 은성에스엠티·은성일렉콤 명칭과 로고 사용 승인
- [ ] PCB, SMT, Ass'y 중 실제 연계 가능한 범위
- [ ] 대응 가능한 수량·보드·부품·검사 범위
- [ ] 일반·긴급 납기와 견적 회신 기준
- [ ] 각 인증서의 유효기간, 적용 법인·사업장·공정

## 증거와 표현

- [ ] 공개 가능한 수행사례와 사진
- [ ] 고객·협력사 이름 및 로고 사용 승인
- [ ] “자체 생산”, “원스톱”, “즉시”, “고신뢰”, “빠른 견적” 같은 표현의 근거
- [ ] 의료기기·방산 관련 공급실적과 진입요건
- [ ] 소프트웨어·로봇·드론 분야의 실제 제공 서비스와 사례

## 홈페이지 구현

- [ ] 주요 전환 목표: 전화, 이메일, 문의 폼 또는 BOM 업로드
- [ ] 업로드할 파일 종류와 보관·삭제 정책
- [ ] 개인정보 수집항목, 동의문과 보유기간
- [ ] 검색 노출을 위한 우선 서비스 페이지
- [ ] 분석·광고 도구와 쿠키 고지 필요 여부
